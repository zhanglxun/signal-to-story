# AI 视频分镜生成 MVP 与生产级演进规划（V3.0）

> **目标**：以极低成本与高扩展性（本地代码运镜算力 + 免费/低价模型额度 + 工业级标杆对齐），建立「剧本大纲 → 导演级分镜拆解 → 角色资产锁定 → 混合镜头动态化（本地运镜 / 万相 AI 视频） → 多轨声音分层剪辑 → Web 可视化控制面」的全链路内容生产系统。  
> **形态**：模块化 Python 视频工厂 + JSON 契约驱动 + Web 可视化控制面，项目资产物理隔离，支持快速向多角色、漫剧、短剧和企业级解说扩展。  
> **验证成果**：
> - **Demo 001（已完成）**：30s 本地 Ken Burns 平滑运镜 + Edge-TTS 毫秒级音画同步 + 智能 BGM Ducking 混音（耗时 3s，成本 ¥0.0）；
> - **Demo 002（已完成）**：通义万相 2.7 真实 AI 动态视频 + 多轨 SFX 拟音分层制作（32MB 高清多轨 AI 视频，已跑通全链路）。

## 1. 行业顶级标杆对标与差距分析（Benchmark & Gap Analysis）

为了保证系统的先进性与扩展性，我们对标了国内顶级 AI 图像与视频生产平台：

### 1.1 标杆平台核心能力解剖
1. **LiblibAI（哩布哩布）—— 资产库与角色一致性之王**
   - **核心杀手锏**：**角色库管理系统（Character Bank）** 与 **ComfyUI 节点工作流**。创作者先入库角色（正/侧面参考图），后续所有分镜调用统一 `Character ID` / `IP-Adapter`，实现跨镜头 100% 锁脸锁衣服。
2. **小云雀（剪映 / 字节跳动）—— 极速分镜工厂与多音轨工业化成片**
   - **核心杀手锏**：**一键剧本秒拆分镜** 与 **可视化卡片表格**。创作者一眼预览全剧分镜，对不满意的那 1 个镜头**独立一键重抽/改台词**；支持多角色声线自动分配（男女老幼不同配音）与智能拟音卡点。
3. **海螺AI（MiniMax / HailuoAI）—— 电影级运镜与动作真实感之王**
   - **核心杀手锏**：**导演模式（Director Mode）**。内置 15 种专业电影镜头语言（特写、过肩拍、希区柯克变焦、环绕推进等）与主体参考（Subject Reference）。

### 1.2 差距对比与定位

| 核心维度 | 行业顶级标杆（Liblib / 小云雀 / 海螺） | 我们的 Video Factory 现状 | 差距与下一步演进动作 |
| :--- | :--- | :--- | :--- |
| **角色一致性** | 角色库（Character Bank）+ 多图主体参考 | 目前主要依靠 Prompt 提示词描述与单图输入 | **【升级动作】建立角色资产库目录，万相/Gemini 多图参考注入** |
| **交互与单镜重抽** | 可视化分镜卡片瀑布流，单镜头一键重新生成 | 目前通过 CLI 和 JSON 驱动，调试需命令行 | **【升级动作】联动 `sense-console` Web 控制面，实现分镜卡片与单镜交互** |
| **镜头语言设计** | 导演级提示词（15 种专业电影运镜语法） | 运镜规则较简单（zoom/pan 基础动效） | **【升级动作】升级 LLM 拆解器，内置导演级镜头语法与景别规则** |
| **声音表现力** | 多角色声线匹配（男女对话）+ 拟音音效 | 已支持 Edge-TTS 单音色 + 自动 SFX 拟音 | **【升级动作】升级多角色对话音色自动分配（Multi-Speaker Routing）** |
| **成本与算力调度** | 纯付费商业平台，成本高昂（¥0.3~0.5/秒） | **冷热混合架构**：本地运镜 + 按需万相 AI 视频 | **【我们的核心护城河】成本低 80% 以上，极速出片且私有可控** |

## 3. 总体流程架构（V3.0）

```text
[Input] 故事大纲 / 选题观点 / 小说剧本 (script.txt)
   │
   ▼ ─── 【Phase 1: 认知与导演级分镜设计 (LLM)】
[T1] Qwen3.7-Max 智能剧本拆解器 (splitter.py)
   │  产出: 包含黄金 3 秒 Hook、多角色切分、景别运镜、镜头类型的 video_plan.json
   │
   ▼ ─── 【Phase 2: 角色资产库注入 (Character Vault)】
[T2] 角色与场景资产管理 (image_engine.py / Character Bank)
   │  注入角色固定三视图与参考图，保障跨镜头形象高一致
   │
   ▼ ─── 【Phase 3: 多角色配音与音效时钟 (Audio-First)】
[T3] 多角色配音 + 独立 SFX 拟音 + 字幕生成 (audio_engine.py + sfx_generator.py)
   │  产出: 逐镜头音频 shot_001.mp3 ... shot_N.mp3，计算出每个镜头的精确时长 (duration_sec)
   │  产出: 独立拟音轨 (sfx/) 与精准对齐的字幕文件 (.srt)
   │
   ▼ ─── 【Phase 4: 混合镜头动态化调度 (Video Engine & Adapters)】
[T4] 混合镜头动态化执行 (video_engine.py):
   │  ├─ 本地动效镜头 (pan_zoom) -> LocalKenBurnsAdapter (FFmpeg 毫秒级生成推拉运镜)
   │  └─ 真实动态镜头 (ai_video) -> 通义万相 2.7 / MiniMax / Seedance / Veo
   │
   ▼ ─── 【Phase 5: 多轨剪辑与最终合成 (FFmpeg Composer)】
[T5] 剪辑合成器 (composer.py):
   │  多镜头无缝拼接 + 画幅归一化 + 多轨独立混音 (Voiceover + BGM Ducking + SFX) + 字幕压制
   │
   ▼ ─── 【Output】
final_video.mp4 + generation_report.json (全流程耗时、成本与血缘审计)
```

## 4. 资产存储与算力协同架构（冷热分层模式）

采用 **“本地热工作区 + 云端持久对象存储 + Postgres 事实账本”** 的分层冷热混合架构：

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                   1. 关系与元数据层 (Supabase / Postgres)                  │
│  只存资产账本: asset_id, storage_uri, mime, hash, 关联的 shot_id/project_id │
└───────────────────────┬──────────────────────────┬───────────────────────┘
                        │ 索引与调度                │ 索引与调度
┌───────────────────────▼───────────┐      ┌───────▼───────────────────────┐
│     2. 本地热工作区 (Hot Cache)     │      │   3. 云端持久对象存储 (Cold Lake) │
│       (Local NVMe / projects/)    │      │  (Cloudflare R2 / OSS / Supabase)│
│                                   │      │                               │
│ ├─ 本地 FFmpeg 剪辑与合成 (0延迟)   │ 同步  │ ├─ 最终成片 (final_video.mp4) │
│ ├─ 临时音频片段 (shot.mp3)        ├─────►│ ├─ 关键参考图 (生成签名 URL 供模型)│
│ ├─ 临时镜头切片 (shot.mp4)        │ (归档)│ ├─ 选中的优质资产与素材库       │
│ └─ 本地模型权重 (SD/CosyVoice)    │      │ └─ Web 控制台多端在线预览与分发 │
└───────────────────────────────────┘      └───────────────────────────────┘
```

## 5. 规范化工程目录结构

代码与工程统一放在 `sense-console/video-factory/`：

```text
sense-console/video-factory/
├── config.yaml               # 全局配置（模型 Key、音色列表、渲染参数、存储配置）
├── requirements.txt          # Python 依赖
├── schemas/                  # 契约与 Schema 校验
│   └── video_plan.json       # 分镜数据规范定义
├── src/                      # 核心执行引擎
│   ├── splitter.py           # Qwen3.7-Max 智能剧本拆解器 (内置导演级 Prompt)
│   ├── audio_engine.py       # Edge-TTS / 多角色配音 + 毫秒级时间戳字幕生成
│   ├── sfx_generator.py      # 独立 SFX 拟音生成器
│   ├── image_engine.py       # 关键帧生图与角色资产注入
│   ├── video_engine.py       # 混合镜头动态化调度 (I2V / 动效)
│   ├── adapters/             # 独立模型驱动层 (热插拔)
│   │   ├── base.py           # 抽象基类 (BaseAdapter)
│   │   ├── local_kenburns.py # 本地平滑推拉/平移动效引擎 (FFmpeg 0成本)
│   │   ├── wanx.py           # 通义万相 2.7 (生图 + 图生视频 + 文生视频)
│   │   ├── minimax.py        # MiniMax 海螺 (H3 / 视频生成)
│   │   ├── seedance.py       # Seedance / 豆包视频模型
│   │   └── veo.py            # Google Veo API
│   ├── composer.py           # FFmpeg 多轨音画剪辑器 (归一化拼接、BGM Ducking、SFX 混音、字幕)
│   └── pipeline.py           # 一键流水线 CLI 入口
├── assets/                   # 通用公共资产
│   ├── fonts/                # 开源中文字体
│   ├── bgm/                  # 背景音乐库 (欢快童趣 / 科技感 / 治愈系)
│   └── characters/           # 全局角色资产库 (Character Bank)
└── projects/                 # 项目工作区（多项目完全隔离）
    ├── demo_kids_candy_001/  # Demo 001 (本地 0 成本运镜版)
    └── demo_kids_candy_002/  # Demo 002 (万相 2.7 AI 视频 + 多轨 SFX 版)
        ├── input_script.txt  # 原始故事大纲
        ├── video_plan.json   # 拆解后的结构化分镜 JSON
        ├── audio/            # 逐镜头配音 MP3
        ├── sfx/              # 逐镜头拟音 MP3
        ├── keyframes/        # 逐镜头关键帧静态图
        ├── shots/            # 逐镜头动态短视频 (万相 2.7 输出)
        ├── subtitles/        # 逐句对齐字幕 (.srt)
        └── output/           # final_video.mp4 + 生成报告 report.json
```
