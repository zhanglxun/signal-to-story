# AI 视频分镜生成与 Web 工作台演进规划（V3.1 - Web 驱动版）

> **目标**：以极低成本与高扩展性（本地代码运镜算力 + 免费/低价模型额度 + 工业级标杆对齐），建立「Web 灵感输入 → 大模型导演级分镜拆解 → 可视化分镜画布 → 角色资产管理 → 混合镜头动态化（本地运镜 / 万相 AI 视频） → 多轨声音分层剪辑 → 在线成片播放」的全链路内容生产控制系统。  
> **形态**：**Web 控制面（Sense Console）为主入口** + 模块化 Python 视频工厂为执行底座 + JSON 契约驱动，项目资产物理隔离，支持快速向多角色、漫剧、短剧和企业级解说扩展。  
> **已交付验证成果**：
> - **Demo 001（已完成）**：30s 本地 Ken Burns 平滑运镜 + Edge-TTS 毫秒级音画同步 + 智能 BGM Ducking 混音（耗时 3s，成本 ¥0.0）；
> - **Demo 002（已完成）**：通义万相 2.7 真实 AI 动态视频 + 多轨 SFX 拟音分层制作（32MB 高清多轨 AI 视频，已跑通全链路）。

## 1. 核心架构决策：Web 控制面先行（从脚本驱动转向 Web 驱动）

根据对产品体验、人机协作（Human-in-the-Loop）以及资产管理的深入评审，**本阶段的核心演进决策是将分镜拆解、内容编辑与资产管理全面移入 Web 控制面（Sense Console）**：

### 为什么在 Web 页面上做大模型拆解与资产管理更优？
1. **告别手动改 JSON 的繁琐**：大模型（Qwen3.7-Max）拆解完直接在界面呈现卡片，创作者可在输入框随时微调台词与 Prompt；
2. **实时视听反馈**：点击即可试听单句配音、预览关键帧，满意后再点击生成万相视频；
3. **单镜头颗粒度控制**：某个镜头不满意，直接在卡片上点击 `[万相重抽]`，仅重新渲染该镜头，不需要重新跑全剧；
4. **统一资产资产库**：脚本、角色图、分镜视频、音轨、成片在 Web 平台可视化归档，随时复用。

## 2. 行业顶级标杆对标与差距分析（Benchmark & Gap Analysis）

为了保证系统的先进性与扩展性，我们对标了国内顶级 AI 图像与视频生产平台：

### 2.1 标杆平台核心能力解剖
1. **LiblibAI（哩布哩布）—— 资产库与角色一致性之王**
   - **核心杀手锏**：**角色库管理系统（Character Bank）** 与 **ComfyUI 节点工作流**。创作者先入库角色（正/侧面参考图），后续所有分镜调用统一 `Character ID` / `IP-Adapter`，实现跨镜头 100% 锁脸锁衣服。
2. **小云雀（剪映 / 字节跳动）—— 极速分镜工厂与多音轨工业化成片**
   - **核心杀手锏**：**一键剧本秒拆分镜** 与 **可视化卡片表格**。创作者一眼预览全剧分镜，对不满意的那 1 个镜头**独立一键重抽/改台词**；支持多角色声线自动分配（男女老幼不同配音）与智能拟音卡点。
3. **海螺AI（MiniMax / HailuoAI）—— 电影级运镜与动作真实感之王**
   - **核心杀手锏**：**导演模式（Director Mode）**。内置 15 种专业电影镜头语言（特写、过肩拍、希区柯克变焦、环绕推进等）与主体参考（Subject Reference）。

### 2.2 差距对比与定位

| 核心维度 | 行业顶级标杆（Liblib / 小云雀 / 海螺） | 我们的 Video Factory 现状 | 差距与演进动作 |
| :--- | :--- | :--- | :--- |
| **交互与单镜重抽** | 可视化分镜卡片瀑布流，单镜头一键重新生成 | 目前通过 CLI 和 JSON 驱动 | **【本阶段优先】在 `sense-console` 构建 Web 可视化分镜画布** |
| **智能剧本拆解** | 一键秒拆分镜、提取黄金 3 秒 Hook 与景别 | 已调通 Token Plan Qwen3.7-Max | **【本阶段优先】在 Web 端接入 Qwen3.7-Max 智能剧本拆解** |
| **角色一致性** | 角色库（Character Bank）+ 多图主体参考 | 目前主要依靠 Prompt 提示词描述 | **【演进动作】在 Web 端建立角色资产卡片，万相多图参考注入** |
| **声音表现力** | 多角色声线匹配（男女对话）+ 拟音音效 | 已支持 Edge-TTS + 自动 SFX 拟音 | **【演进动作】在 Web 端支持分镜多角色音色下拉选择** |
| **成本与算力调度** | 纯付费商业平台，成本高昂（¥0.3~0.5/秒） | **冷热混合架构**：本地运镜 + 按需万相 AI 视频 | **【核心护城河】成本低 80% 以上，极速出片且私有可控** |

## 3. 总体流程架构（V3.1）

```text
[Web Input] 网页端输入故事大纲 / 选题观点 / 模板选择
   │
   ▼ ─── 【Phase 1: Web 驱动的导演级分镜拆解 (Qwen3.7-Max)】
[T1] 网页调用 Qwen3.7-Max，生成并展示分镜卡片流 (Storyboard Cards)
   │  创作者在页面上微调台词、Prompt、镜头类型 (本地运镜 vs 万相 AI 视频)
   │
   ▼ ─── 【Phase 2: 角色资产与音色配置 (Character & Voice)】
[T2] 页面分配角色参考图与音色 -> 实时调用 AudioEngine 在线试听
   │
   ▼ ─── 【Phase 3: 视觉关键帧与万相视频生成 (Image & Video Engine)】
[T3] 页面触发生成关键帧与万相 2.7 动态视频，支持单镜头卡片级重抽与回显
   │
   ▼ ─── 【Phase 4: 多轨剪辑与在线播放 (Composer)】
[T4] 剪辑合成器完成多镜头拼接 + 多轨独立混音 (Voiceover + BGM Ducking + SFX) + 字幕
   │
   ▼ ─── 【Web Output】
网页内嵌播放器即时播放 final_video.mp4 + 生成报告面板与资产归档
```

## 7. 评估指标与验收标准

| 评估指标 | 测量方法 | 目标值 |
|---|---|---|
| **大模型分镜拆解耗时** | 页面输入大纲到分镜卡片全部呈现 | ≤ 5 秒 |
| **在线交互体验** | 页面直接修改台词并试听配音 | 点击即听，0 延迟 |
| **单镜头独立重抽** | 点击单个卡片重新调用万相 | 仅重跑当前镜头，不影响全片 |
| **Web 一键成片导出** | 页面点击合成到视频播放器弹出 | ≤ 5 秒 |
