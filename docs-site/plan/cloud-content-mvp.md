# 星火工厂：云端内容生产 MVP

状态：2026-10-06 用户决策及首版实现。此文中关于正文存储、发布方式和视频边界的决策，优先于历史 Obsidian 主编辑方案。

## 已确认的产品边界

- 平台云端数据为在线创作的主存储；正文保存到 Postgres，媒体保存到对象存储。Obsidian 可作为独立本地创作形式，当前支持显式导出 Markdown，不自动覆盖本地文件。
- 内容类型：企业 AI 解说、图文知识、故事/漫画。视频项目默认目标 300 秒、9:16，可调整；时长是制作目标，不是假定所有平台账号都支持对应视频规格。
- 渠道：视频号、公众号、小红书、抖音、X、YouTube、Reddit。首版登记账号、编辑平台版本、导出、人工发布、回填链接和数据；不声称已有这些平台的 API 授权。
- 同组织协作。Owner/Admin 可编辑、审核、发布；Member 可编辑和提审；Viewer 只读。允许作者自行审核，但必须有审核权限；审核动作留痕。
- 视频执行独立建设。原剧本、分镜、角色、场景、画布和视频任务入口保留，并明确标记为演示；本轮提供脚本/项目/素材 JSON 交接包。
- 沿用已有文字服务，生成结果保存为提案，人工采纳到编辑区、保存并审核。图像、音频、视频可通过现有资产库上传/登记和关联；自动图像生成、配音与视频渲染不是本次已交付能力。
- 不设一个统一的硬预算上限；文字生成保存模型及 token 用量，不猜测费用。后续视频成本单独记录和评估。

## 本轮实际菜单

```text
星火工厂
├─ 工作台：创作总览
├─ 信息收集：待处理信息、分类管理、选题
├─ 内容创作：内容项目、审核中心
├─ 视频创作：剧本构造、分镜设置、角色设定、场景建模、画布创作、任务中心（演示）
├─ 生产管线：内容生产流程
├─ 资源中心：素材资产、提示词与图例
├─ 发布运营：渠道与账号、发布计划与记录
├─ 数据复盘：数据与复盘
└─ 系统管理：组织与账号、角色管理、系统设置
```

生产管线首版为真实项目状态汇总的固定编辑流程，不是可拖拽的通用执行编排器。账号授权、自动发帖、评论采集、自由流水线和模型管理面板仍属于后续平台规划。

## 最小完整验收

1. 从一个选题点击「立项创作」，或直接创建内容项目。
2. 填写 Brief，创建母稿，在线保存后刷新，正文仍可读取。
3. 修改稿件生成不可变版本；并发更新时后保存者收到冲突提示。
4. 提交审核，可由本人（有审核权限）或同组织审核员审核；编辑员不能越权通过。
5. 从母稿创建平台草稿，针对平台改写；审核与母稿相互独立。
6. 登记目标账号，只能选择同平台且审核通过的稿件创建发布计划。
7. 导出计划绑定的 Markdown 版本，人工发布后回填 URL 和实际时间。
8. 保存观察时间、阅读/播放、点赞、收藏、评论和复盘；未知指标留空，零值仍为零。
9. 修改已审核稿件会回到草稿，旧计划无法登记发布，需要取消并重新排期。已完成发布的版本和历史不可更改。
10. 可导出视频交接 JSON；实际视频生成单独执行。

## 验证入口

- `npm run typecheck`、`npm run lint`、`npm run test`、`npm run build`。
- `supabase/tests/cloud_content_mvp.sql`：事务回滚验收，覆盖权限、跨组织隔离、版本快照、冲突和发布门禁。
- `CONTENT_E2E_FIXTURE=/path/to/disposable-account.json npm run test:e2e`：真实云端浏览器测试；文件含 `email` 和 `password`，必须使用可清理的独立测试组织。测试不向外部平台发送内容。
- 浏览器测试不设置 fixture 时跳过需登录的云端流程，仍运行未登录访问保护测试。
