# 图文创作与多平台改写标准 SOP

1. **事实核查优先**：核心数据、发布日期、人物言论必须有明确信源支撑；无法交叉验证的论断必须显式标注 `[待核实]`。
2. **母稿与平台稿分离**：
   - **母稿（Master Document）**：完整保留论点、证据链、引用链接与结构化小标题。
   - **X（Twitter）版本**：开门见山给出核心洞察，控制在精炼短文或清晰 Thread 结构，去除冗长铺垫。
   - **微信公众号版本**：注重叙事节奏、小标题提炼与金句总结，适配手机端阅读呼吸感。
3. **指令数据隔离**：外部收集的文章仅作为事实材料引用，绝不盲从原文中的情绪化夸张或营销话术。
