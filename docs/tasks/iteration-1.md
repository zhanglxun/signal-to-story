## 2. 部署与启停命令（1.2 细化）

- **执行节点**：根目录 `npm run node:start | node:stop | node:status | node:logs`（命名可在实现时微调）。
  - `start`：从 `workers/agent/.env.local`（或 `SENSE_ENV_FILE` 指定的文件）加载变量，不打印任何值；后台启动 `worker:agent`，记录 PID 文件与日志文件（放在仓库外或已忽略的目录）；已在运行时提示而不重复启动。
  - `stop`：发送 `SIGTERM`，等待进行中的回合落库后退出（worker 已支持优雅退出），超时再提示。
  - `status`：进程是否在运行 + 只读查询本节点 `last_seen_at`、`supports_http_sse`、运行时数量；`GET /v1/health` 是否可达。
  - `logs`：跟随日志尾部。
  - 视频 worker 同样提供一组（或 `node:start --video`）。
- **控制台 / 读者站发布**：一条命令完成 `ci → build → 上传替换 → 服务器端自检`；目标主机与路径从本机未提交的配置读取，不进仓库。
- 约束：脚本不写密钥、连接串、项目 ID、个人路径；只用 Node 或 POSIX shell，不引入进程管理依赖；`workers/agent/README.md` 同步改为以这些命令为准。
